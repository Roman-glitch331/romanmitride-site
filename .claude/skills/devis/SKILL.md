---
name: devis
description: "Traiter une demande de devis reçue via le formulaire du site : lire, résumer, préparer une réponse en brouillon. N'envoie rien."
---

1. La demande arrive sur contact@romanmitride.fr (boîte à ne pas modifier). Lire le message seulement s'il est fourni.
2. Résumer : organisateur, type d'événement, date, lieu, budget, surface (`technique` dans `site.ts`).
3. Préparer un brouillon de réponse (vouvoiement, prix « à partir de » de `tarifs`, rien d'inventé).
4. Présenter à Roman. Aucun envoi sans son accord ; pour les relances et le suivi, voir le Gestionnaire.
